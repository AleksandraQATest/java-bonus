# Калькулятор бонусных миль (Java)

Простая консольная программа на Java для расчёта бонусных миль за покупку билета.

## Как работает программа

- Стоимость билета — 10 000 рублей.
- За каждые 100 рублей начисляется 1 бонусная миля.
- Программа рассчитывает количество миль и выводит результат в консоль.

## Результат работы

```text
Начислено бонусов: 100
```

## Технологии

- Java 11
- Maven

## Запуск

Открыть проект в IntelliJ IDEA и запустить метод `main` в файле `Main.java`.
